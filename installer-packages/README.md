Installer Packages for Foder
=============================

This directory contains distribution packages for Foder (Local AI Coding Agent).

## Contents

### .deb (Ubuntu/Debian)
- `foder_0.1.0_all.deb` - Debian package

### Windows (.exe)
- `windows/install.bat` - Windows batch installer

### Linux/macOS
- `linux/install.sh` - Shell installer script

## Installation Instructions

### Ubuntu/Debian:
`bash
sudo dpkg -i foder_0.1.0_all.deb
`

### Windows:
`batch
start install.bat
`

### Linux/macOS:
`bash
./install.sh
`

## Notes

- Installers are designed for local installation.
- The binaries require Ollama to be installed separately.
- For detailed installation instructions, refer to the main README.md.
